# Stanley Garage Doors

A website for Stanley Garage Doors

Built with Next.js.

## Prerequisites

Make sure you have the following installed:

- [Git](https://git-scm.com/)
- [Node.js](https://nodejs.org/) v18+
- pnpm v8+ (install with npm install -g pnpm or corepack enable)

## Installation

1. **Clone the repository**

   ```bash
   git clone https://github.com/Palmetto-Dev-and-Design/stanley-garage-door.git
   cd stanley-garage-door
   ```

2. **Install dependencies**

   ```bash
   pnpm install
   ```

## Running the Project

Start the development server:

```bash
pnpm dev
```

Then open [http://localhost:3000](http://localhost:3000) in your browser.
